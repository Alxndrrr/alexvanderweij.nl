# Alex van der Weij

Static personal landing page for `www.alexvanderweij.nl`.

## GitHub Pages

Publish from the repository root on the `main` branch.

Custom domain:

```text
www.alexvanderweij.nl
```

DNS at the domain host:

```text
www  CNAME  <github-username>.github.io
```
